# ارزیابی منبع tablokhani.com

تاریخ بررسی: ۱۴۰۵/۰۷/۰۱

## نتیجه

سایت روی صفحهٔ اصلی و صفحهٔ عمومی نماد خروجی HTML واقعی می‌دهد. API عمومی مستندشده یا مجوز بازنشر API پیدا نشد؛ ابزارهای «پول داغ»، «بازی بازار»، «بازی بزرگان»، امتیاز هوش مصنوعی، اختیار معامله و سیگنال‌ها بخشی از اشتراک تجاری‌اند و در تابلورادار خوانده نمی‌شوند.

## محدودیت‌های مشاهده‌شده

- `robots.txt` مسیر عمومی `/` را مجاز کرده است.
- مسیرهای حساب، پنل، پرداخت، مدیریت و مسیرهای `realtime-*` صریحاً ممنوع‌اند؛ کلاینت تابلورادار این مسیرها را پیش از شبکه رد می‌کند.
- صفحهٔ اصلی عمومی شاخص‌ها، صف‌ها و جدول نمادهای پرحجم را نمایش می‌دهد.
- صفحهٔ عمومی نماد قیمت‌ها، حجم/ارزش، دامنه مجاز، پنج سطح سفارش و حقیقی/حقوقی را نمایش می‌دهد.
- بخش قابل‌توجهی از تحلیل‌های اختصاصی نیازمند خرید اشتراک است؛ هیچ دورزدن ورود یا اشتراکی انجام نمی‌شود.
- API داخلی سایت، WebSocket و endpointهای realtime مهندسی معکوس یا فراخوانی نمی‌شوند.
- در محیط فعلی اتصال مستقیم Python با TLS بسته شد؛ بنابراین منبع فقط fallback است و موفقیت آن جعل نمی‌شود.

## نحوهٔ استفاده

`tsepy/tablokhani_source.py` فقط HTML عمومی را با User-Agent استاندارد می‌خواند، حداکثر پنج نماد عمومی را برمی‌گرداند و سه دقیقه cache دارد. داده با این مشخصات وارد می‌شود:

- `kind: live-partial`
- `provenance: tablokhani.com-public`
- `synthetic: false`
- `partial: true`

اگر چهار فیلد پایهٔ `pl/pc/tvol/tval` صریحاً در صفحه نباشند، رکورد رد می‌شود. هیچ مقدار گمشده‌ای حدس زده نمی‌شود. این منبع بعد از BrsApi، TSETMC و بورس‌تریدر و پیش از اسنپ‌شات محلی قرار دارد.
