# سیاست اتصال BrsApi در تابلورادار

مبنای این پیاده‌سازی، مستندات رسمی BrsApi در تاریخ ۱۴۰۵/۰۷/۰۱ است.

## قراردادهای مصرف‌شده

- بازار: `AllSymbols.php?key=…&type=1`
  - `type=1`: سهام بورس و فرابورس، ETF و حق‌تقدم.
  - خروجی JSON شامل قیمت، معامله، حقیقی/حقوقی و پنج سطح عرضه/تقاضا است.
- تاریخچه قیمت: `History.php?key=…&type=0&l18=…`.
- کلید فقط از متغیر محیطی `BRS_API_KEY` در `server.py` و CLI خوانده می‌شود.
- User-Agent کامل مرورگر ارسال می‌شود؛ مستندات سرویس UA پیش‌فرض پایتون را قابل مسدودشدن می‌داند.

## انطباق با قوانین سرویس

1. کلید شخصی است: در کد، Git، HTML، localStorage، URL مرورگر، لاگ یا خروجی JSON ذخیره نمی‌شود.
2. فراخوانی مستقیم مرورگر و CORS Proxy برای BrsApi حذف شده است؛ همهٔ درخواست‌ها server-side هستند.
3. تابلورادار API عمومیِ بازنشر BrsApi راه‌اندازی نمی‌کند؛ `/api/market` فقط backend همان برنامه است و کلید را تحویل نمی‌دهد.
4. محدودیت اعلام‌شده ۳۰۰ درخواست در ۵ دقیقه رعایت می‌شود: بازار ۴۵ ثانیه cache و تاریخچه ۳۰ دقیقه حافظه/۷ روز دیسک دارد.
5. پاسخ کوتاه، JSON نامعتبر، خطای کلید یا دادهٔ شبیه‌سازی‌شده پذیرفته نمی‌شود؛ سامانه fail-closed است.
6. به‌علت امکان تغییر ساختار سرویس، آرایه فقط از قراردادهای شناخته‌شده `list/data/result/rows` پذیرفته می‌شود.

## راه‌اندازی امن

```bash
export BRS_API_KEY='…'
python3 server.py
```

برای production، متغیر را در secret manager میزبان تنظیم کنید؛ آن را در `.env` داخل پروژه یا command line عمومی قرار ندهید.

## وضعیت حذف TSETMC

حذف کامل مسیر TSETMC فقط پس از یک probe موفق واقعی BrsApi انجام می‌شود. تا وقتی TLS/شبکهٔ میزبان اجازهٔ تأیید کلید و ساختار پاسخ را نداده، TSETMC به‌عنوان fallback واقعی باقی می‌ماند؛ هیچ موفقیتی فرض یا جعل نمی‌شود.
