# TabloRadar — تابلورادار

**سامانه کمی اسکن، تابلوخوانی و رتبه‌بندی بورس تهران — ۱۰ سیگنال برتر در <۲ ثانیه**

لندینگ + داشبورد زنده تک‌فایل (`index.html`) با موتور پایتون ۳.۱۱ برداری (Pandas/httpx/pyarrow/rich) — بدون فریم‌ورک وب. داده زنده از **BrsApi (مبتنی بر CDN رسمی TSETMC)** با متدولوژی `tablokhani.com`.

> ⚠️ سلب مسئولیت: صرفاً ابزار تحلیل داده است، توصیه سرمایه‌گذاری نیست.

---

## ویژگی‌ها

- **اسکن ۷۳۰ نماد** با Inner-Join دیده‌بان × حقیقی‌حقوقی روی `insCode`
- **تابلوخوانی برداری:** سرانه خرید، قدرت خریدار/فروشنده، حجم مشکوک `tVol/MA30`، عدم تعادل دفتر سفارش (OBI ۵ سطح)، تیک صعودی
- **تکنیکال چندبازه:** RSI(14)، EMA(9/21)، SMA(20/50/200)، MACD، بولینگر — نمره‌دهی ۰..۱۰۰ هر افق
- **امتیاز جامع:** `Score = 0.35·T + 0.25·S + 0.25·M + 0.15·L` با نگاشت سیگموئید
- **۳ فیلتر وتو:** ارزش معاملات < ۵۰ میلیارد ریال، حجم < حجم مبنا، صف فروش قفل
- **خروجی:** جدول `rich` + `signals.json` + لندینگ تعاملی (دونات، تیکر، اسپارک‌لاین، ترمینال)

## دموی زنده

```bash
python3 -m http.server 8000
# باز کنید http://localhost:8000
```

یا مستقیم `index.html` را در مرورگر باز کنید (CORS از طریق زنجیره `direct → althost → corsproxy/allorigins/codetabs` هندل می‌شود).

## نصب و اجرا (پایتون)

```bash
pip install httpx pandas pyarrow rich
python main.py          # تک‌اجرا
python main.py --loop   # زمان‌بندی روزانه 12:25
```

> نیازمند **Python 3.11+**. کلید نمونه BrsApi در `config.py` است؛ در پروداکشن از `env` یا Worker/Proxy بخوانید.

## ساختار ۷ ماژول

```

```
